Since you're building a clock (<p class="clock">10:20</p>), I assume you want to do this in JavaScript to display the time dynamically.

Here are the 4 best ways to extract just the time from that string, depending on what exactly you want:

Method 1: Keep the exact time from the string (Ignore Timezone)

If you want 12:59:32 (ignoring the +03:00 offset and just cutting the string):

javascript

Download
const dateString = "2026-08-08T12:59:32.450737+03:00";
const time = dateString.split('T')[1].split('.')[0]; 
console.log(time); // Output: "12:59:32"

To show only hours & minutes (like your 10:20 example):

javascript
Copy
Download
const time = dateString.split('T')[1].slice(0, 5); 
console.log(time); // Output: "12:59"

Method 2: Convert to the user's local timezone

If you want to display the time in the user's local timezone (e.g., if they're in New York, it converts from 12:59 +03:00 to 05:59 -04:00):

javascript
Copy
Download
const date = new Date("2026-08-08T12:59:32.450737+03:00");
const time = date.toLocaleTimeString('en-US', { 
    hour: '2-digit', 
    minute: '2-digit',
    second: '2-digit',
    hour12: false // Use true if you want AM/PM
});
console.log(time); // Output: "05:59:32" (if in NY) or "12:59:32" (if in +03:00)

Method 3: Using Regex (cleanest one-liner)

This grabs everything between the T and the . (or +):

javascript
Copy
Download
const dateString = "2026-08-08T12:59:32.450737+03:00";
const time = dateString.match(/T(\d{2}:\d{2}:\d{2})/)[1];
console.log(time); // Output: "12:59:32"

Method 4: The Modern Intl.DateTimeFormat (best for formatting)

If you want full control over formatting (e.g., 12:59 PM or 12:59:32):

javascript
Copy
Download
const date = new Date("2026-08-08T12:59:32.450737+03:00");
const time = new Intl.DateTimeFormat('en-US', {
    hour: '2-digit',
    minute: '2-digit',
    second: '2-digit',
    hour12: false,
    timeZone: 'UTC' // Remove this to show local time, or keep 'UTC' to show the raw time
}).format(date);
console.log(time); // Output: "12:59:32"
